## How to Run 
1. Open the repository in Visual Studio Code.
2. Navigate to the `week02` folder and open `HelloWorld.java`.
3. Open a terminal in VS Code and compile the program using:
   ```bash
   javac week02/HelloWorld.java
   ```
4. Execute the compiled program using:
   ```bash
   java week02.HelloWorld
   ```
